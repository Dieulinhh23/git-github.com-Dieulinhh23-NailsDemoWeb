# Nail Salon Landing Page

## Goal
Build the first public-facing page for the capstone: a refined nail salon website that introduces the business, showcases services, and gives visitors a clear path toward future online booking.

## What I’ll build
- Replace the blank home screen with a complete, responsive landing page.
- Create a distinctive editorial beauty direction with warm neutrals, deep berry accents, crisp typography, and salon-focused imagery.
- Add a focused top navigation and prominent “Book an appointment” calls to action.
- Include first-view salon messaging, featured service previews, a salon experience section, trust details, and a concise footer.
- Keep booking actions honest for this phase: they will scroll visitors to the service area rather than pretend a booking system already exists.
- Add mobile-friendly layouts, accessible controls, subtle motion, and reduced-motion support.
- Add page-specific title, description, and social metadata.

## Technical details
- Use the existing React/TanStack application and Tailwind design tokens.
- Define the complete visual system in the global stylesheet with semantic colors and reusable page patterns.
- Generate and store cohesive nail-salon imagery within the project rather than hotlinking stock images.
- Keep this phase frontend-only; no database, authentication, booking logic, staff tools, or notifications.
- Validate the finished page at desktop and mobile sizes in the browser.
